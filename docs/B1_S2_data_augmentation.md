# R1.3 B1-S2 — 数据增补方案（方案 A）详细设计

**日期**: 2026-08-13
**依据**: `docs/R1.3_PLAN.md` §3（方案 A）、`docs/B1_S1_root_cause_analysis.md` 根因
**范围**: 设计方案文档；**本 B1 批次不执行数据生成**（执行属 B2 批次，涉及 data/scripts，需新任务）

---

## 1. 目标

针对根因"同名/邻接存根类 hard_irrel 覆盖不足"，增补样本使模型学会**"内容证据否决表层相似"**，将 R12-VALL-0005 类持久 False REL 消除（R1.3 目标 1：False REL 1→0）。

## 2. 增补样本类型（5 类）

| 类型 | 定义 | 示例线索 | 标签 |
|---|---|---|---|
| T1 同名存根 | 候选文件名/函数名与目标模块同名或同义，内容为空存根/占位（`def ...(*args, **kw)`、`pass`、`TODO`） | `target_module.py` vs 目标本体 | IRREL |
| T2 近名变体 | 候选带 `_v2/_neighbor/_helper/_proto` 等后缀，内容与目标无功能/数据依赖 | `context_bucket_neighbor.py`（R12-VALL-0005 原型） | IRREL |
| T3 邻接实体 | 真实相邻/调用链上模块，但候选内容与当前 TASK 修复点无关（无数据流、无故障点证据） | 调用链文件但仅声明未使用 | IRREL |
| T4 目标本体对照 | 候选确为修复目标本体/真实依赖，内容含相关证据 | 目标源码含故障点 | REL（对照组，防增补破坏 REL 分布） |
| T5 跨任务对比对 | 同一候选路径在 TASK-A 下 REL、在 TASK-B 下 IRREL（内容证据不同），强化"证据决定相关性" | 同文件，A 任务涉其数据流，B 任务无关 | 成对 REL/IRREL |

## 3. 数量与分布目标

| 项 | 目标 |
|---|---|
| 增补总量 | **100–120 条**（`train_batch5.jsonl`） |
| hard_irrel 占比 | ≥ 55%（含 T1+T2+T3 合计 ≥ 30 条，聚焦根因） |
| 其中 T1+T2（存根/近名） | ≥ 20 条（直接覆盖 R12-VALL-0005 类） |
| REL 占比 | 35–45%（T4+T5 的 REL 半边），维持类别平衡 |
| 真实 R1.1 片段 | ≥ 30%（沿用 T345 机制：来源只读、内容去重） |
| 跨任务对比对（T5） | ≥ 10 组（每组成对出现） |

## 4. 来源与去重约束

- 真实片段来源：R1.1 冻结目录（**只读**，同 T345 real_samples 机制 + exclude_contents 内容去重）；
- 合成模块命名沿用 `_v2` 隔离规则（同 T345 修正），避免与 R1.1 跨 split 文本冲突；
- 去重标准（沿用 T348 决策）：以 **(task, element, path) 组合** 判定；与 train_batch1–4、valid_all 零重叠（组合 + 候选文本两个口径）；
- 新增约束：T5 对比对内部必须组合唯一（同一 path 在 batch5 内允许多个 task 上下文，但 (task,path) 唯一）。

## 5. 标注规则

1. 标签仅由**候选内容证据**决定，不受名称/路径相似影响（Rule–Element–Evidence 判定式）；
2. 空存根/占位无功能证据 + 无调用/数据流证据 → **IRREL**（即使名称与目标高度相似）；
3. 候选内容含目标故障点/修复点证据或真实数据依赖 → **REL**；
4. 存疑样本（无法由内容证据判定）不生成，避免噪声；
5. 候选内容**禁止内嵌标签提示语**（REL/IRREL/相关/对应本模块/归档等词 0 命中，QA 正则扫描验证）。

## 6. 验收标准（B2 执行时）

- [ ] 分布达标：hard_irrel ≥55%，T1+T2 ≥20 条，T5 ≥10 组，真实片段 ≥30%；
- [ ] 与 train_batch1–4 + valid_all 零重叠（组合 + 文本）；
- [ ] 批内重复组合 0，提示语残留 0；
- [ ] 合并后 `train_all_r13.jsonl` 覆盖 R12-VALL-0005 同类场景 ≥5 个变体（样本 ID 清单留档）。

## 7. 风险评估

- 过度拟合单一案例风险：T1/T2 需覆盖多任务（≥10 个不同 TASK），避免只围绕 packet_builder；
- 类别失衡风险：T5 对比对成对生成，REL/IRREL 同时增长，分布可校验；
- 与 R1.2 冻结数据关系：batch5 为**新增**数据，不修改 train_all.jsonl（R1.2 冻结文件保持原样，R1.3 用新合并文件）。
