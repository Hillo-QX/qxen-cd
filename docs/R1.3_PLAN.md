## 2. R1.3 阶段目标（可量化）

1. **消除持久 False REL**: R12-VALL-0005 类 hard_irrel（同名/邻接模块存根、表层相似候选）误判 REL 从 **1 → 0**（valid 20 条与 Shadow 5 条两个口径）
2. **Shadow accuracy 提升**: 0.80 → **≥ 0.90**（5 样本中 ≤ 0 例 False REL；按 20 样本 valid 口径不得低于 0.95 为硬约束，防过拟合回退）
3. **保持既有指标不退化为前提**: valid acc ≥ 0.95、False IRREL = 0、invalid = 0 作为回归护栏
4. **新增评估维度（证据可审计性）**: 判定输出附带 evidence 引用（判定依据的候选内容片段/路径），Shadow 级可审计率 **≥ 80%**（4/5 样本可追溯判定理由）

## 3. R1.2 失败模式提炼与改进方向

**失败模式（源自 R1.2 报告 §5）**: R12-VALL-0005 目标「扩容 packet_builder」，候选 `qxen/context_bucket_neighbor.py`（同名函数存根 `def context_bucket(*args, **kw)`）——路径/名称表层相似、内容证据不足以否决时，模型倾向 REL（materiality over-recall 方向）。非退化信号，属 hard_irrel 固有挑战。

**候选干预方向（A–D，源自 R1.2 报告 §5 建议）**:
- **A. 数据增补**: 增补 hard_irrel 同名/近名/邻接模块存根类样本，强化"内容证据否决表层相似"判别
- **B. 判定校准**: hard_irrel 类别引入置信度阈值/校准（REL 判定要求更高证据强度）
- **C. 证据引用输出**: 判定输出附 evidence 引用，False REL 可审计（沿用 shadow 置信度代理思路，先解决区分度）
- **D. 判定协议增强**: prompt 侧强化"候选内容证据 vs 表层相似"权重提示（不修改已冻结数据，属推理侧变更）
