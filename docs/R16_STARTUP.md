**日期**: 2026-08-13

## 1. 核心目标

**一句话目标**: 将 R1.5 正式判定协议 `decide()`（scripts/r1.5/r15_rule_refine.py）接入批量预测入口（命令行/批处理脚本），对任意候选路径列表输出"判定标签 + 判定依据（reason）"双字段结果，且 39 条 R1.5 总评估集 acc=1.0 不回退。

依据 R15_CLOSURE_REPORT §4 下一步建议：
- 第 1 条（R1.5 闭环登记为方法论标准）已在 T368 完成；
- 第 2 条（短期可选）：decide() 当前为独立评估脚本，未接入业务管道 → 本阶段执行；
- 第 3 条（方案C 特征注入微调）为中期方向，依赖评估集规模扩大，**不在本阶段执行**；
- 第 4 条（"判定+依据"双字段审计）与 R1.3 溯源可审计率目标联动 → 本阶段一并落地。

本阶段**不训练、不调用 Ollama、不修改冻结模型**，为纯工程接入与审计强化。

## 3. 验收标准（客观可度量）

1. **入口可用**: `scripts/r1.6/` 下存在批量预测入口脚本，接受 jsonl 输入（每行含 task/elements/candidates 等既有评估集字段），输出预测结果文件，每行含 `label`（REL|IRREL）与 `reason`（判定依据）双字段。
2. **零回退**: 以 R1.5 总评估集 39 条（data/r15_stability/eval_stability.jsonl 15 条 + B1/C 24 条回归）经批量入口重跑，acc=1.0，FR=0，FI=0（与 R1.5 闭环一致，无回退）。
3. **双字段审计 100%**: 批量入口输出中每条样本的 `reason` 非空且可溯源（含置信带区间与/或 F1/F2 规则命中详情），审计覆盖率 100%（R1.3 溯源目标 ≥80% 之上提升至 100%）。
4. **性能量级不变**: 批量入口规则判定部分开销保持 R1.5 量级（≤0.05 ms/样本；R1.5 实测 0.0102 ms/样本）。

## 4. 停止条件

- 39 条评估任一 acc < 1.0 或 FR > 0 或 FI > 0（判定回退）；
- 验收标准（§3）任意一条无法客观验证；
- 需要修改 §2.2 冻结路径下任何文件；
- 需要调用 Ollama 或任何模型（本阶段无训练/推理调优）；
- 需要读取 `调度状态/任务账本.json` 全文。

触发任一停止条件即停止并上报，不做盲目重试。
