# LocalQwen adapter boundary

This optional integration is Apache-2.0 for adapter code authored here. The
LocalQwen/Qwen model, tokenizer, runtime, and any downloaded weights remain
under their own upstream licenses.

The adapter is advisory only. It may distill or classify material, but it must
not alter audit denominators, Gate results, business task counts, or final
decisions. Model outputs must pass the same deterministic guard before entering
stable context.

No Ollama endpoint, model cache, local path, or private configuration is
included in this repository.
